# Centralized Decision Engine Logic & Design Assumptions

This document describes the decision rules, configurable thresholds, and operational rationale used in `backend/app/services/decision_engine.py`.

---

## 1. Design Philosophy

The decision engine does **NOT** use a trained machine-learning classifier to output `BUY_NOW`, `WAIT`, or `REJECT`. Instead, it applies transparent, configurable policy thresholds to the output distributions generated by the Monte Carlo simulation.

All thresholds are centralized in [`backend/app/config.py`](file:///a:/HarvestIQ/backend/app/config.py).

## 2. Configurable Decision Thresholds

```python
DECISION_CONFIG = {

    "MEAN_SPOILAGE_REJECT_THRESHOLD": 0.60,      # If mean spoilage rate > 60% -> REJECT
    "MIN_PROFIT_HURDLE_INR": 500.0,              # Minimum positive EFV required to avoid REJECT
    "WAIT_MIN_ADVANTAGE_INR": 1200.0,            # Delayed EFV must beat Day 0 by at least ₹1200
    "WAIT_MAX_PROB_LOSS": 0.15,                  # Do not recommend WAIT if probability of loss > 15%
    "WAIT_MAX_SPOILAGE_P95": 0.35,               # Do not recommend WAIT if 95th percentile spoilage > 35%
    "CHANGE_OPTION_MIN_ADVANTAGE_PCT": 0.12,     # Mandi option must beat Direct Processing by > 12%
    "MIN_RELIABILITY_FOR_STRONG_REC": 60.0       # If reliability < 60%, append CAUTION flag
}
```

*Status:* These values are **Initial Configurable Prototype Design Assumptions** calibrated to South Indian agricultural transport corridors. They are fully editable without altering core business logic.

## 4. Operational Rationales

1. **`REJECT` (Defensive Risk Safeguard):** Protects the processing unit from purchasing low-grade lots that decay in transit or holding areas, preventing unrecoverable freight and labor losses.
2. **`CHANGE_OPTION` (Arbitrage Opportunity):** Identifies when open-market APMC wholesale prices exceed factory contract procurement prices by a sufficient margin (>12%) to cover auction fees.
3. **`WAIT` (Harvest Timing Optimization):** Advises farmers to delay picking by 3 to 7 days only when expected market price appreciation outpaces cumulative spoilage decay.
4. **`BUY_NOW` (Immediate Offtake):** Standard recommendation when current market conditions lock in positive net return with minimal biological decay risk.
